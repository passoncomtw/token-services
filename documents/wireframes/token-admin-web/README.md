# Token Admin Web Wireframe

## 概述

Token Admin 是一個管理後台系統，用於管理用戶、訂單、銀行資訊和收付帳戶。

## 頁面結構

### 核心功能頁面

1. **登入頁面** (`login.html`)
   - 管理員登入介面
   - 簡潔的登入表單

2. **用戶管理** (`user-list.html`, `user-detail.html`)
   - 顯示所有用戶列表
   - 查看用戶詳細資訊
   - 用戶頭像使用 [Pravatar](https://pravatar.cc/)

3. **訂單管理** (`order-list.html`, `order-detail.html`, `order-history.html`)
   - 所有訂單列表（含待處理訂單標籤頁）
   - 訂單詳情
   - 訂單歷史記錄

4. **銀行管理** (`bank-management.html`)
   - 管理銀行資訊
   - 新增和編輯銀行資料

5. **收付帳戶** (`payment-accounts.html`)
   - 管理收付帳戶資訊

## 設計規範

### 圖片來源

- **用戶頭像**: [Pravatar (https://pravatar.cc/)](https://pravatar.cc/)
  - 格式: `https://i.pravatar.cc/150?u={用戶ID}`
  
- **產品/其他圖片**: [Lorem Picsum (https://picsum.photos/)](https://picsum.photos/)
  - 格式: `https://picsum.photos/seed/{種子}/200`

- **Logo**: 使用純文字樣式
  - 登入頁面: "TOKEN ADMIN" + "管理後台系統"
  - 側邊欄: "TOKEN ADMIN"

### 色彩系統

```css
--primary: #ffcc00          /* 主要強調色 - 黃色 */
--secondary: #15151b        /* 次要色 - 深灰黑 */
--success: #0dc884          /* 成功狀態 - 綠色 */
--warning: #ff8e00          /* 警告狀態 - 橙色 */
--danger: #ff4a46           /* 危險狀態 - 紅色 */
--info: #00BCD4             /* 資訊狀態 - 青色 */
```

### 導航結構

所有頁面共用統一的側邊欄導航：

- 用戶管理
- 訂單管理
- 銀行管理
- 收付帳戶

### 使用者介面元素

- **登出按鈕**: 所有管理頁面的右上角都有登出按鈕
- **側邊欄 Logo**: 使用黃色 "TOKEN ADMIN" 文字
- **登入頁面 Logo**: 使用大型 "TOKEN ADMIN" 標題配以副標題

## 功能特點

### 用戶管理
- 查看用戶列表
- 查看用戶詳細資訊（基本資料、訂單記錄、掛單記錄、收付帳戶、登入歷史）
- 用戶狀態顯示（活躍/禁用）

### 訂單管理
- 標籤頁式設計：所有訂單、待處理訂單、訂單歷史
- 訂單狀態篩選（已完成、待付款、處理中、已取消）
- 訂單類型篩選（買入、賣出）
- 日期範圍篩選
- 訂單詳情查看

### 待處理訂單
- 整合在訂單管理的標籤頁內
- 等待確認、申訴處理、超時訂單分類
- 卡片式顯示
- 快速操作（確認、查看詳情）

## 開發指南

### 查看頁面
直接在瀏覽器中打開 HTML 文件即可查看效果。

### 修改樣式
所有樣式都內嵌在 `<style>` 標籤中，可以直接在文件中修改。

### 統一修改
如需統一修改所有頁面的側邊欄或頂部欄，需要在每個頁面文件中分別修改。
