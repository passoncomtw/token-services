# 購物商城 APP Wireframes (第一版)

## 概述

這是購物商城 APP 的第一版 wireframes，專注於核心的購物與訂單流程。第一版只包含單一商家的商品瀏覽、購物車、結帳（使用綠界金流）和訂單管理功能。

## 設計理念

- **簡潔流程**：移除第一版不需要的功能（商家選擇、搜尋、設定等）
- **單一商家**：第一版專注在單一商家的商品銷售
- **第三方金流**：使用綠界金流處理付款，無需自建結帳頁面
- **行動優先**：專為手機設計的 iOS 風格介面
- **完整流程**：涵蓋瀏覽、購物、結帳、訂單查詢的完整流程

## 頁面架構

### 核心頁面 (8 個)

```
登入 (login.html)
  ↓
商品列表 (home.html)
  ↓
商品詳情 (product-detail.html) → 加入購物車
  ↓
購物車 (shoppingcar.html) → 前往綠界結帳

[綠界金流結帳頁面 - 外部]

  ↓
訂單列表 (orders.html) ↔ 訂單詳情 (order-detail.html)
  
使用者資訊 (profile.html)
```

## 頁面說明

### 1. 登入頁面 (`login.html`)
- **功能**：使用電話與密碼登入
- **特色**：
  - 漸層背景設計
  - 已填入示範帳號方便測試
  - 移除註冊和忘記密碼功能
- **測試帳號**：
  - 電話：0912345678
  - 密碼：password123

### 2. 商品列表 (`home.html`)
- **功能**：顯示單一商家的所有商品
- **特色**：
  - 商家名稱：美好生活商城
  - 搜尋商品功能
  - 購物車數量提示
  - 精美的橫幅廣告
  - 網格式商品展示
  - 底部導航列（首頁/購物車/訂單/我的）
- **商品資訊**：名稱、價格、庫存狀態

### 3. 商品詳情 (`product-detail.html`)
- **功能**：查看單一商品的詳細資訊
- **特色**：
  - 大圖展示
  - 商品描述
  - 評價和庫存資訊
  - 數量選擇器
  - 加入購物車按鈕
- **操作**：選擇數量後可加入購物車

### 4. 購物車 (`shoppingcar.html`)
- **功能**：管理購物車中的商品
- **特色**：
  - 顯示所有購物車商品
  - 調整商品數量
  - 刪除商品
  - 顯示總金額
  - 前往結帳按鈕（導向綠界）
- **結帳流程**：點擊「前往結帳」會導向綠界金流頁面

### 5. 訂單完成 (`order-success.html`)
- **功能**：顯示付款成功畫面
- **特色**：
  - 成功動畫效果
  - 訂單編號
  - 付款方式
  - 訂單金額
  - 訂單日期
- **操作**：查看訂單詳情或返回首頁

### 6. 訂單列表 (`orders.html`)
- **功能**：顯示所有歷史訂單
- **特色**：
  - 訂單卡片式展示
  - 訂單編號和狀態
  - 商品縮圖
  - 訂單金額
  - 快速查看詳情按鈕
- **訂單狀態**：已完成、處理中、待付款

### 7. 訂單詳情 (`order-detail.html`)
- **功能**：查看單筆訂單的詳細資訊
- **特色**：
  - 訂單狀態卡片
  - 訂單基本資訊
  - 商品明細
  - 金額計算（商品小計、運費、總計）
  - 訂購人資訊
- **資訊**：訂單編號、時間、付款方式、商品清單、金額

### 8. 使用者資訊 (`profile.html`)
- **功能**：顯示使用者基本資料
- **特色**：
  - 漸層頭部設計
  - 使用者頭像
  - 基本資訊（姓名、電話、Email）
  - 購物統計（訂單數、累計消費、加入日期）
  - 登出功能
- **資訊展示**：

## 綠界金流整合

### 結帳流程
1. 使用者在購物車點擊「前往結帳」
2. 系統跳轉至綠界金流頁面：
   ```
   https://payment.ecpay.com.tw/Cashier/AioCheckOut/V5
   ```
3. 使用者在綠界完成付款
4. 付款成功後返回 APP
5. 顯示訂單完成頁面（order-success.html）

### 注意事項
- 第一版 wireframe 中的連結為示範用
- 實際整合需要後端處理綠界 API
- 需要設定正確的回傳網址（ReturnURL）
- 需要處理付款通知（NotifyURL）

## 測試流程

建議按以下順序測試：

1. 開啟 `login.html` → 點擊登入
2. 進入 `home.html` → 瀏覽商品
3. 點擊任一商品 → 進入 `product-detail.html`
4. 調整數量 → 點擊「加入購物車」
5. 進入 `shoppingcar.html` → 確認商品
6. 點擊「前往結帳」（會導向綠界網址）
7. 直接開啟 `order-success.html` 查看完成頁面
8. 點擊「查看訂單詳情」→ 進入 `order-detail.html`
9. 或從底部導航進入 `orders.html` → 查看所有訂單
10. 底部導航點擊「我的」→ 進入 `profile.html`
